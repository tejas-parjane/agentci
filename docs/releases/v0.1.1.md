## Install

```bash
pip install agentci-py
# to run an existing openai-agents app through the gate without a rewrite:
pip install "agentci-py[openai-agents]"
```

## What it is

AgentCI records what your agent actually does, replays recorded behavior against
later code, diffs the two traces, and gates releases on the difference. The flow
a release runs: **record → replay → diff → block** — each a real command with a
real exit code.

```text
$ agentci record --name refund          # capture today's behaviour as ground truth
$ agentci replay .agentci/traces/refund.jsonl        # run the scenario again, answered only from the recording
$ agentci diff .agentci/traces/refund.jsonl ...refund-replay.jsonl   # name the change
$ agentci gate                          # RELEASE GATE: BLOCKED on regression
```

The 60-second quickstart in the README reproduces the full block from a clean
`pip install` on a deterministic scripted model — no API key.

## Highlights

- **`agentci.integrations.openai_agents`** — run an existing `agents.Agent`
  (handoffs included) through AgentCI with zero rewrite: every function tool
  routes through the policy/mock/replay registry, and model calls are traced.
- **Trace Specification v1** — the normative contract for `trace.jsonl`, with
  byte-for-byte pinned examples.
- **Deterministic replay** — recordings answer outrank mocks and live code; a
  call the recording never saw is refused (`replay: divergent`), never silently
  "fine".
- **Behavioral diff** — event kinds, order, tool identity, arguments, statuses;
  latency/cost/tokens reported as measurements, not behavior.
- **Change-aware selection** — `run --changed`/`gate` only run the tests the
  diff can affect, with reasons recorded.
- **Async tool routing** — `ToolRegistry.ainvoke()` with the same policy layers.
- **Safety defaults** — external side effects denied unless mocked, forbidden
  data redacted at serialization, budgets and loop detection stop runaway runs.
